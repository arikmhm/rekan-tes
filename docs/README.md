# Dokumentasi Rekan Tes

Sumber keputusan produk dan teknis MVP. Satu keputusan tinggal di satu dokumen; dokumen lain menautkannya.

- [PRD.md](./PRD.md) — aturan produk, definisi selesai MVP, dan keputusan yang masih terbuka.
- [USECASE.md](./USECASE.md) — diagram use case dan pemetaannya ke kode.
- [DATABASE_DESIGN.md](./DATABASE_DESIGN.md) — alasan model data dan aturan yang tidak terbaca dari schema.
- [TECH_STACK.md](./TECH_STACK.md) — stack, konvensi, dan jebakan teknis (Base UI, DOKU).
- [DESIGN.md](./DESIGN.md) — design system visual (warna, tipografi, aturan copy).
- [ISSUES.md](./ISSUES.md) — backlog; pekerjaan berikutnya adalah issue berstatus `Next`.
